## Visual and timing direction
- Approximately 20 seconds total: screens 1–2 about 0–7s, 3–4 about 7–11s, ticker screen 5 about 11–15s, screen 6 about 15–17s, screen 7 about 17–20s. Exact beats and loop seam reviewed before animation.
- Use Patkan's saved cream, ink and orange palette and approved Patkan lockup. Screens 1–2 show a recognizable white ChatGPT chat interface, with the prompt transforming **in the same input area**. `//` is orange. Do not recreate the ChatGPT logo: obtain the original from OpenAI's official brand materials and use it unaltered only if its usage guidelines permit this demonstration; otherwise use the text “ChatGPT” and ask for approval before image work. Browser names are text, not fabricated logos.
- The transformed prompt is an **illustrative draft**, not a claim that a real Patkan run produced these exact words. The script deliberately asks for unknown hiring facts instead of inventing them.
