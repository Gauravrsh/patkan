# Patkan Brand Command Centre for Adobe Express

Build one upload-ready pack matching the Adobe Express brand sections in your screenshots: Logos, Colors, Fonts, Graphics — plus a copy-paste cheat sheet for the Overview fields.

## What you get

A new folder `/mnt/documents/patkan-adobe-brand-kit/` containing:

### 1. Cheat sheet (`patkan-brand-cheatsheet.md` + PDF)
Everything typed into Adobe on your phone, in copy-paste blocks:
- Brand name: `patkan.in`
- Tagline (under 120 chars) and short overview
- The five hex codes in palette order, each with a name and where it is used
- Font names with role (headline / body / mono) and the Adobe-library fallbacks
- A short "how to upload" walkthrough matching the screens you sent: Add > Logo, Add > Color palette (Custom > Hex), Add > Font (Upload), Add > Graphic

### 2. Logos folder (all with the `patkan.in` wordmark — never `patkan` alone)
Each as PNG (2048px, transparent) and SVG:
- Square mark, light background version
- Square mark, dark background version
- Horizontal lockup (mark + `patkan.in`), light and dark
- Wordmark only `patkan.in`, light and dark
- The `/पट्कन/` pronunciation badge, light and dark

### 3. Colour palette (core 5, in priority order)
- Cream paper `#F3EFE4`
- Ink `#1C1917`
- Patkan orange `#D96C2C`
- Muted text `#4B4643`
- Hairline rule `#D5CFC2`
Delivered as a hex list to type in, plus a swatch PNG for reference.

### 4. Fonts (both routes)
- Upload files: Fraunces (display) and Inter (body/UI) static TTFs in the weights actually used, packaged in a `fonts/` folder ready for Adobe's Upload button.
- Fallback names: closest equivalents already inside Adobe Express, listed in the cheat sheet in case an upload is rejected.

### 5. Graphics
The reusable brand elements as transparent PNG/SVG: the orange progress ribbon, the hairline rule, the orange section-number dot, and the `//` token mark.

### 6. `patkan-adobe-brand-kit.zip`
The whole folder zipped, for desktop upload in one go.

## Notes

- Existing assets in `/mnt/documents/patkan-brand-assets/` and the brand bible are the source of truth; nothing in the app or website changes.
- Wordmark rule is enforced everywhere: the logo always reads `patkan.in`.
- Every exported file is opened and visually checked for crop, transparency, and colour accuracy before delivery.
