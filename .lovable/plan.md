# Patkan LinkedIn Carousel Templates — Text Mockups

Three template sets, all 1080×1350px (LinkedIn portrait carousel), built strictly on Patkan brand: cream paper (#F3EFE4), ink (#1C1917), orange accent (#D96C2C), Fraunces for display, Inter for body, lowercase headlines, ruled hairlines, generous margins, quiet "paper and ink" feel. Each slide has clear lorem ipsum placeholders at distinct type scales. Each set is a system of 3 layouts: cover, content slide, closing/CTA slide.

## Production notes (after approval)

- Output: PNG, 1080×1350px per slide, one set = cover + content + closing (9 files total), plus a repeat of each content slide to show series flow if wanted.
- Fonts: Fraunces (display) + Inter (body/labels) — matching the site exactly.
- Palette locked to site tokens: cream #F3EFE4, ink #1C1917, orange #D96C2C, muted ink variants.
- All lorem ipsum placeholders are sized and spaced so real copy can drop in without reflow.
- Delivered as downloadable files; can also be bundled into a single PDF for easy review.
